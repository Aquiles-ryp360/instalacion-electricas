# Referencias de clase y avance

Esta carpeta conserva formatos y documentos externos recibidos en clase para
preparar presentaciones, requerimientos y cuadros de insumos. No pertenece a un
proyecto personal especifico; sirve como referencia comun para el repositorio.

Archivos:

- `REQUERIMIENTO N 02 ELECTRICAS (2).xlsx`: formato institucional de cuadro de
  insumos. La columna clave para el trabajo de cotizacion es `CODIGO DEL BIEN`.
- `REQUERIMIENTO_tubo de cobre_3.8_3.4._pararrayo_cinta aislante.docx`:
  documento de apoyo con requerimientos y ejemplos de insumos electricos.

Uso previsto:

1. Mantener estos archivos como evidencia original recibida.
2. Usar el `.xlsx` solo como referencia de formato, no como fuente canonica del
   BOM.
3. Generar archivos editables nuevos en `build/` o `entregables/` mediante las
   herramientas de `herramientas/cotizacion/`.
