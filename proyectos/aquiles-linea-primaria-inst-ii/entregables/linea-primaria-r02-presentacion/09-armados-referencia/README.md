# Referencias DGE

Se conserva íntegra la recopilación documental anterior. Su portada identifica LP-R01 como procedencia; únicamente las 23 hojas normativas A3 se anexan al expediente integrado P01. No se reactivan la línea ni los cálculos R01. Las piezas de madera, giros especiales y capacidades no equivalen automáticamente a un armado CAC de LP-R02. Ver las observaciones técnicas del paquete.

El DXF/DWG de `04-planos` incorpora las 23 referencias vectorizadas en pestañas `REF-DGE-*`; los planos propios son `LP-01` a `LP-19`. Son CAD derivados de copias normativas, con texto trazado como contornos; no archivos DWG oficiales emitidos por MINEM ni cotas paramétricas. No utilizar estas hojas como adaptación CAC aprobada. El modelo principal conserva sus 111 postes R02.
