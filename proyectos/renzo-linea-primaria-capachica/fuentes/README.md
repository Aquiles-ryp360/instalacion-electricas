# Fuentes Originales del Proyecto

En esta carpeta se almacenan las fuentes primarias y evidencias originales del proyecto (no modificar ni sobreescribir):
- `kml/`: Archivo KML/KMZ de Google Earth con la ruta y puntos de la línea primaria.
- `gisem/`: Capturas y datos oficiales del geovisor GISEM OSINERGMIN de Electro Puno.
- `topografia/`: Perfil generado por TopoMagic en formato original (.top, .dxf o .csv).
