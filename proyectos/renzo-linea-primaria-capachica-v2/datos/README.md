# Datos Canónicos del Proyecto

- `topografia/`: Perfil procesado de progresivas, cotas del terreno y ángulos de deflexión.
- `conductores.yaml`: Parámetros técnicos del conductor (sección, diámetro, peso, tiro de rotura, módulo elástico E, coeficiente dilatación alpha, resistencia eléctrica, reactancia inductiva).
- `estructuras.yaml`: Tipos de postes de CAC (12/300, 12/400, 13/400) y armados normalizados DGE (alineamiento, ángulo, anclaje, seccionamiento).
- `cargas.yaml`: Cuadro de cargas, abonados y potencia proyectada de la subestación.
